  When invoked, perform the following steps in a workspace-safe manner
  (configured for `cosmic-wallshift`):
  1. Detect Rust workspace in `cosmic-wallshift` and locate `Cargo.toml`/
    `Cargo.lock` files.
  2. Use `cargo outdated` (or `cargo search` when unavailable) to detect
    newer versions for dependencies.
  3. For each candidate update, pin the **exact** new version in the
    `Cargo.toml` using `cargo add <crate>@<version>` when available, or
    edit the manifest directly when necessary.
  4. Run a minimal verification: `cargo check` (no full test-suite runs by
    default per workspace settings).
  5. If verification succeeds and at least one dependency was updated,
    create a branch off `main`, commit the `Cargo.toml` changes, push the
    branch, and open a PR using the repository remote/URL (do not use
    `gh` by default).
  6. If verification fails, create an issue with reproducible steps and do
    NOT open a PR.

  Safety: never push directly to `main`. Always create a feature branch and
  open a PR for review. This agent will not run the full test suite unless
  explicitly requested.

Description
-----------

This custom agent is focused on dependency maintenance for Rust projects in
this workspace. It is intended to be picked when you need an automated, low-
noise PR that bumps crate versions, verifies the change, and surfaces CI
results for human review.

When to pick this agent
-----------------------

- Use when you want periodic or on-demand dependency checks across the
  workspace.
- Do not pick if you need broad refactorings or non-dependency changes.

Suggested example prompts
-------------------------

- "Recheck dependencies and open PR against main if updates exist."
- "Run cargo outdated for cosmic-wallshift and create PR with bumps."
